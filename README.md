# MeritEd

An educational management platform that derives student identity from learning behavior, not just scores.

## What is MeritEd?

Most educational platforms measure what you submitted. Not how you learned.

MeritEd tracks the behaviors that actually drive learning — participation, persistence, helping others, and recovery after setbacks — and reflects them back as a meaningful student identity.

Two students can have identical XP and completely different identities. One earned it through assessments. One earned it by helping peers. The platform knows the difference.

## Core Concepts

- **Behavioral Identity** — student identity derived from XP source distribution, not total score
- **Accumulative Progression** — XP only increases, no punishment for setbacks
- **Recovery System** — late work is always possible, at a reduced multiplier
- **Discussion and Collaboration** — structured peer interaction with credibility system (in progress)
- **Badge System** — milestone rewards that reinforce behavioral diversity
